BMI-Stratified Survival Analysis

Statistical analyst | R, Survival Analysis, TCGA

Overview

Compared survival across BMI categories in TCGA kidney cancer clinical data using Kaplan-Meier curves and log-rank tests.

Is body mass index associated with survival in kidney cancer patients? The clinical data records BMI as a continuous value, which first has to become a usable grouping.

Tools

  • R
  • survival
  • survminer
  • TCGA clinical data

Role

Statistical analyst. UBC bioinformatics course lab.

Description

  • Engineered a five-level BMI class variable following CDC ranges.
  • Generated Kaplan-Meier survival curves and risk tables for each class.
  • Tested differences between groups with the log-rank test and interpreted the result in clinical context.

Outcome

The lab reinforced feature engineering from clinical variables and hypothesis-driven survival analysis with clear reporting.
