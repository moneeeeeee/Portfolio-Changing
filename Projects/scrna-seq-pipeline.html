Sequence Alignment & RNA-seq Read Quality

Individual assignment | R, SAM Parsing, Custom Algorithms

Overview

Implemented pairwise alignment by dynamic programming in R, then parsed SAM files from single-cell RNA-seq data to compute quality metrics.

Aligners and their output files are usually treated as black boxes. This assignment opens them: implement the alignment algorithm, then read real alignment files and measure their quality.

Tools

  • R
  • SAM format
  • dynamic programming

Role

Individual assignment. UBC bioinformatics course.

Description

  • Implemented pairwise sequence alignment with custom scoring matrices, gap penalties and mismatch scores, and verified results by tracing the traceback by hand.
  • Parsed SAM headers and reads to extract metadata, total aligned reads and per-chromosome mappings.
  • Converted ASCII base-quality strings to Phred scores and computed mean base quality by chromosome.
  • Filtered to genomic subregions, flagged reads below quality thresholds and plotted score distributions as boxplots.

Outcome

The work gave me a concrete understanding of alignment algorithms, sequencing file formats and quality control, and of how coverage bias can affect biological conclusions.
