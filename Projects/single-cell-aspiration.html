Automated Single-Cell Aspiration System

Electrical and software systems lead | Arduino, MATLAB, SolidWorks, Fritzing

Overview

A closed-loop Arduino controller that holds suction within ±0.5 kPa in a microfluidic device that isolates single cells.

A microfluidic device captures a single cell by negative pressure. The suction has to be held steady at a chosen level throughout the experiment, which is hard to do by hand.

Key Numbers

±0.5 kPapressure held around target
4person team

Tools

  • Arduino
  • MPX5010 pressure sensor
  • INA125 amplifier
  • stepper motor
  • MATLAB
  • Fritzing
  • SolidWorks

Role

Electrical and software systems lead. UBC design project, team of four.

Description

  • Built a feedback loop on an Arduino Uno that compares live pressure with a target set by a potentiometer and steps a motor to adjust suction.
  • Conditioned the pressure sensor signal with an instrumentation amplifier.
  • Tested the control logic in MATLAB before moving to hardware.
  • Streamed live data to Excel so the team could monitor pressure during cell loading.
  • Designed the circuit layout in Fritzing and integrated valve control with the biological loading phase.

Outcome

The system maintained pressure within ±0.5 kPa of the target. Leading one subsystem taught me to define the interface with the biology side early, since valve timing depended on their loading protocol.
