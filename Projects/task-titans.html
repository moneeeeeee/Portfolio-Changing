Task Titans (in progress)

Personal project | Node.js, Express, MongoDB, JWT, JavaScript

Overview

A chore-competition app: a REST API with 14 endpoints for accounts, groups, logging and leaderboards, plus a browser stopwatch client.

Clean Clash showed that timing chores is more fun as a competition, but it only works for one person in one browser. Task Titans adds accounts, groups and shared leaderboards, which meant learning backend development outside my coursework.

Role

Personal project. Individual, ongoing.

Description

  • Designed the data model for users, groups, tasks and timed logs in MongoDB.
  • Built signup and login with bcrypt password hashing and JSON Web Tokens; each new user gets a private group automatically.
  • Protected routes with token verification and group-membership checks.
  • Wrote leaderboard logic for best times, per-user averages over daily, weekly and monthly ranges, daily summaries and percentile feedback against a user's own history.
  • Built a stopwatch client that logs a timed chore to every group the user belongs to.

Outcome

The backend and stopwatch client work locally. Charts and deployment are the next steps, and I plan to rebuild the service in Python with FastAPI. The project taught me how much design lives in the data model.
