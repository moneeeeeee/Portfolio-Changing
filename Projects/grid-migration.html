Grid Migration Simulator

Developer | Java, Gradle, JUnit

Overview

An agent-based city simulation in Java where residents move across a grid based on satisfaction, crowding and fairness.

How do individual decisions to stay or move add up to city-wide patterns such as congestion and clustering? The difficulty in simulating this is consistency: if agents move one at a time, earlier moves change what later agents see.

Tools

  • Java
  • Gradle
  • JUnit
  • object-oriented design

Role

Developer. UBC software construction course.

Description

  • Designed modular classes for agents, buildings, walkways and time tracking.
  • Implemented a two-step update that computes every agent's decision before applying any, keeping grid state consistent within a time step.
  • Made satisfaction thresholds, reset conditions and density limits configurable.
  • Automated builds with Gradle and tested movement logic and stability with JUnit.
  • Built TimeSeries objects that record agent placement over time for analysis.

Outcome

The simulation showed how local rules produce system-level behaviour, an idea that carries over to load balancing and pedestrian flow. Course policy keeps the code private.
