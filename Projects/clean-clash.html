Clean Clash Timer

Personal project | HTML, CSS, JavaScript

Overview

A browser stopwatch that ranks your five fastest times per chore and tells you when you set a personal best.

I wanted a quick way to make chores competitive, and a first project that stores data in the browser.

Live demo Source code

Tools

  • HTML
  • CSS
  • JavaScript
  • localStorage

Role

Personal project. Individual.

Description

  • Built a start, stop and reset stopwatch with a per-chore leaderboard.
  • Stored attempts in localStorage as milliseconds so ranking stays correct for any duration.
  • Added personal-best feedback and options to clear one chore or all of them.

Outcome

Clean Clash is the single-player prototype that led to Task Titans. It taught me to store raw values instead of formatted text and to keep storage and rendering logic separate.
